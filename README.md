# ☁ Cloud-Based File Upload and Retrieval System

A web-based cloud storage simulation that allows users to upload, list, download, search, and manage files using centralized local storage.

## Features

- File upload
- File listing
- File download
- File deletion
- File search
- Professional dashboard UI
- Drag-and-drop file upload
- File size and upload information
- Centralized local storage

## Technology Stack

- HTML
- CSS
- JavaScript
- Python
- Flask
- Local File System
- REST APIs

## Project Architecture

User
↓
Web Browser
↓
Flask Backend
↓
Local Storage (/uploads)
